Values in a Compose file can be set by variables and interpolated at runtime. Compose files use a Bash-like
syntax `${VARIABLE}`. Both `$VARIABLE` and `${VARIABLE}` syntax is supported. 

See [substitution syntax](/reference/compose-file/interpolation.md#substitution-syntax), [literal dollar signs](/reference/compose-file/interpolation.md#use-a-literal-dollar-sign), and [unresolved variables](/reference/compose-file/interpolation.md#unresolved-variables).
