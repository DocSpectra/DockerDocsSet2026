## Tasks

The .NET getting started guide teaches you how to create a containerized .NET application using Docker. In this guide, you'll learn how to:

- [Containerize and run a .NET application](containerize.md)
- [Set up a local environment to develop a .NET application using containers](develop.md)
- [Run tests for a .NET application using containers](run-tests.md)
- [Configure a CI/CD pipeline for a containerized .NET application using GitHub Actions](configure-ci-cd.md)
- [Deploy your containerized application locally to Kubernetes to test and debug your deployment](deploy.md)

After completing the .NET getting started modules, you should be able to containerize your own .NET application based on the examples and instructions provided in this guide.
