Use the prerequisites linked from your guide.

## Docker installed

You must have Docker installed. To install Docker, see [Get Docker](/get-started/get-docker.md).

## Docker Desktop

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)

## Docker Desktop installed and running

You must have [Docker Desktop](/manuals/desktop/_index.md) installed and running.

## Latest Docker Desktop

Install the latest version of [Docker Desktop](/get-started/get-docker.md).

## Node.js and yarn

- [Node.js](https://nodejs.org/en/download/package-manager) and [yarn](https://yarnpkg.com/)

## Git client

You have a [Git client](https://git-scm.com/downloads). The examples use a command-line based Git client, but you can use any client.
