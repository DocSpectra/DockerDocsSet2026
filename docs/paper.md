This package contains the Docker artifacts used for the ICSC 2027 submission: the documentation versions, question sets and support judgments of the paper's Docker application. In that application, the paper measures how the original documentation and the two experimental refinements differ in directed link structure, and evaluates retrieval and answering on the question sets described here. The paper's numerical results, analysis code and evidence records are in [DocSpectra/DocSpectraICSC2027](https://github.com/DocSpectra/DocSpectraICSC2027); this package does not restate them.

The dataset citation in [`CITATION.cff`](../CITATION.cff) stands on its own. Cite the paper separately once it is published, and cite Docker's documentation as the upstream source.

This page will carry the public manuscript link when one exists. Until then no DOI, acceptance or publication is claimed.
