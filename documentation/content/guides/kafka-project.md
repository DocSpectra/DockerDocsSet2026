## Prerequisites

[Docker Desktop](prerequisites.md#docker-desktop) and [Node.js and yarn](prerequisites.md#nodejs-and-yarn).

Basic knowledge of Kafka and Docker.

## Get the project

1. Clone the [GitHub repository](https://github.com/dockersamples/kafka-development-node) locally.

   ```console
   $ git clone https://github.com/dockersamples/kafka-development-node.git
   ```

2. Navigate into the project.

   ```console
   cd kafka-development-node/app
   ```

3. Install the dependencies using yarn.

   ```console
   $ yarn install
   ```
