# Licenses and terms

DockerDocsSet2026 combines material with different origins. Source citation and licensing are separate obligations: cite Docker's documentation as the upstream source whatever terms apply.

| Material | Where | Origin | Terms |
| --- | --- | --- | --- |
| Original Docker documentation | `docs-original`: `documentation/`, `upstream-pages/` | docker/docs at commit `274681c` | Apache License 2.0, as stated by docker/docs at that commit ("Copyright 2013-2026 Docker, Inc., released under the Apache 2.0 license"). Docker's `LICENSE` is copied unchanged into each documentation branch. docker/docs had no NOTICE file at that commit. |
| Vendored reference pages | `docs-original`: `upstream-pages/_vendor/` | Pages that docker/docs vendors from docker/buildx v0.33.0, docker/cli v29.4.0, docker/compose v5.1.2, docker/model-runner v1.1.36, moby/buildkit v0.29.0 and moby/moby/api v1.54.1 (versions from docker/docs `_vendor/modules.txt`) | Not verified for this package (see Open items). These pages are outside the experiment corpus and appear only in the upstream snapshot. |
| Refined documentation | `docs-lt`, `docs-r0`: `documentation/` | Docker documentation modified and extended by an automated editing agent during the study | Derivative of Apache-2.0 material. Each branch carries Docker's `LICENSE` and a `NOTICE.md` stating that files were changed; [`manifests/changes-lt.csv`](manifests/changes-lt.csv) and [`manifests/changes-r0.csv`](manifests/changes-r0.csv) list every changed and added file. Terms for the editing contributions are not yet assigned (see Open items). |
| Corpus exports and link graphs | `export/`, `historical-export/` on the branches | Mechanical transformation of the documentation | Same terms as the documentation they are derived from. |
| Tier-2 questions and reference answers | `questions/tier2/` | Headings and text extracted verbatim from Docker's FAQ pages | Apache License 2.0 (Docker documentation). |
| Tier-1 tasks, requirements and generation records | `questions/tier1/`, `protocol/tier1-generation/` | Generated by a language model from Docker documentation excerpts and revised in author review; quotations are Docker text | Not yet assigned by the author; see Open items. Until terms are published, no license is granted for this material beyond what applies to the Docker text it contains. |
| Support judgments, populations and manifests | `judgments/`, `questions/*/populations.jsonl`, `manifests/` | Study annotations: LLM verifier output and derived records | Not yet assigned by the author; see Open items. Until terms are published, no license is granted for this material beyond what applies to the Docker text it contains. |
| Documentation pages and tools | `README.md`, `docs/`, `tools/`, `protocol/` | Written for this package | Not yet assigned by the author; see Open items. Until terms are published, no license is granted for this material beyond what applies to the Docker text it contains. |

## Open items

- **Package terms.** The author has not yet chosen terms for the package's own material (annotations, generated tasks, judgments, manifests, documentation and tools). This is a release decision.
- **Modification notices.** Apache License 2.0 section 4(b) asks that modified files carry prominent notices of the change. To keep the recorded tree identities, the refinement branches give this notice in `NOTICE.md` and in per-file change lists instead of editing each file. Whether that is sufficient is a release decision.
- **Vendored pages.** The license files of the six vendored source repositories at the listed versions were not inspected for this package.
